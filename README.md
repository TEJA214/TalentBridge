
# TalentBridge

## University Internship Management Platform

TalentBridge is a web-based platform designed to connect university students with employers and help manage internship opportunities and applications.

## Current Features

- Student dashboard
- Opportunity search
- Opportunity details
- Application form
- MySQL database integration
- Pug templates and shared layout

## Technologies Used

- Node.js
- Express.js
- MySQL
- Pug
- HTML and CSS
- Docker

## Project Structure

- `app/` – Application routes and database services
- `app/views/` – Pug templates
- `static/` – CSS and static files
- `index.js` – Application entry point
- `docker-compose.yml` – Docker configuration
